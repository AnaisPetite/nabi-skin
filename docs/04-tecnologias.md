# Tecnologías del proyecto — Nabi Skin

> Guía: [Tecnologías del proyecto](../evaluacion/guias/fase-1-requerimientos/04-tecnologias.md)

## Stack

| Área | Herramienta | Para qué la uso |
|---|---|---|
| Construcción | HTML + CSS | Maquetar las páginas de Nabi Skin sin depender de un gestor de contenido. |
| Versionado | Git y GitHub | Guardar el avance del proyecto  con commits en la nube. |
| Publicación | GitHub Pages | Publicar la tienda y blog de Nabi Skin gratis con una URL pública. |
| Diseño | Whimsical | Armar el moodboard con la estética coreana y hacer los wireframes.|
| Diseño | Google Stitch | Generar el prototipo visual de alta fidelidad para la marca. |
| IA | Gemini | Ordenar ideas y redactar los textos enfocados en Sofía. |
| Editor | Antigravity | Escribir el código HTML/CSS con ayuda de la IA. |

## Qué es funcional y qué es prototipo

| Funcionalidad | Estado en esta versión |
|---|---|
| Navegación entre la landing, el blog y la tienda de Nabi Skin | Funcional |
| Ver detalle de productos (ej:serúm, protector solar y guía de uso) | Funcional |
| Consultar por WhatsApp para asesoría de piel | Funcional |
| Compartir artículos de K-Beauty o productos | Funcional |
| Formulario de captación para la guía gratuita de K-Beauty | Prototipo Visual |
| Buscador y filtros por tipo de piel | Prototipo Visual |
| Carrito de compras y cálculo de despachos por comuna | Prototipo Visual |
| Comentarios y reseñas de los usuarios en el blog | Prototipo Visual |


## Integraciones para una versión real

- Pasarela de pagos: Webpay o Mercado Pago.
- Despacho: Integración con una empresa de courier en Chile para calcular costos de envío.
- Email marketing: Herramienta como Mailchimp o Klaviyo para guardar los correos de usuarios y enviar la guía gratuita de K-Beauty junto con el descuento.


## Restricciones

- **Plazo:** 29 de septiembre a 14 de octubre
- **Marca:** no hay manual de la marca
- **Dispositivos:** el sitio debe funcionar en celular y escritorio, priorizando la experiencia móvil
